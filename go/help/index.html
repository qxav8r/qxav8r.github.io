Quick start

Floggy-Go reads an eCrew report you've saved and sends the flights to LogTen Pro. There are two import pages:

  • Floggy-Go Schedule for the Personal Crew Schedule Report, one bid month at a time, with crew, scheduled times and duty times.
  • Floggy-Go Logbook for the Pilot Logbook report: flown legs with actual times, tail, landings, P1/P2 and Part 121/91.

On the road, Floggy-Go Flifo fills in actual out/in times and tail from Alaska's flight status. See Flifo below.

For one trip, Floggy-Go Pairing reads a saved pairing and shows the trip rig, sends the legs to LogTen and makes calendar files. See Pairing below.

  1. Save the report from eCrew as a CSV file.
  2. Open the matching Floggy-Go page and tap Choose … CSV.
  3. Check the preview. Uncheck any leg you don't want.
  4. Tap Send to LogTen. LogTen opens and imports.

Using both? Send the schedule first and the logbook last. Both write to the same LogTen flights (matched by flight number, date and route), and the logbook has the final say on P1/P2 and Part 121/91.

Your file never leaves your device. The page reads it in the browser and hands the flights straight to LogTen.

Getting the CSV from eCrew

Each Floggy-Go page needs its own eCrew report, saved as a CSV file:

  • Schedule: the Personal Crew Schedule Report, one bid month (or a custom date range).
  • Logbook: the Pilot Logbook report for the dates you want. A year at a time keeps it tidy. Keep each report within one base.
  • Schedule: eCrew → Schedule → My Schedule → Print, then the file/export icon → Save as Text (.csv).
  • Logbook: eCrew → Reports → Pilot Logbook Report, then Save as Text (.csv).

On iPad the file goes to the Files app (usually Downloads). On Mac it goes to your Downloads folder. Then pick it with the Choose … CSV button.

Put Floggy-Go on your device

iPad

  1. Open the Floggy-Go page in Safari.
  2. Tap Share (the square with the up arrow) → Add to Home Screen.
  3. From then on, launch it from its icon like an app.

Mac

  1. Open the Floggy-Go page in Safari.
  2. Bookmark it, or use File → Add to Dock.
  3. The Choose … CSV button opens a normal file window.

The screen, top to bottom

  1. Header shows which version you're in (Schedule or Logbook) and its version number and date.
  2. Choose … CSV picks your report. The file name appears beside it. Until you pick one, an example file is loaded so you can see how things work. Nothing from the example is yours.
  3. Info banner shows the report period and how times are read. Logbook reminds you that logbook times are in base time: if you changed bases, pull a separate report for each base.
  4. Summary boxes show the pilot, base and seat, when the report was generated, and counts of flights, deadheads, sims, ground, reserve and warnings. Check that the name and dates are what you expect.
  5. Switches control what gets sent (next section).
  6. Leg table has one row per leg or duty. Checked rows are sent. On iPad, swipe the table sideways to see more columns.
  7. Send box holds Send to LogTen and Copy LogTen URL.
  8. LogTen package (tap to open) shows exactly what Send passes to LogTen. You can ignore it unless you're curious.

Sending

  • Send to LogTen opens LogTen and imports the checked rows. LogTen adds new flights and updates ones it already has.
  • You can send the same report again at any time, for example after flying the trip. Flights are updated, not duplicated.
  • Flights you've locked in LogTen are skipped without any message.
  • Nothing reaches LogTen until you tap Send.

Floggy-Go Flifo

Floggy-Go Flifo looks up a flight on Alaska's public flight status and sends the actual out time, in time and tail number to LogTen. Use it on the road to fill in a trip as you fly it, after importing your schedule.

  1. Type the flight number. The date starts at today; change it for a flight on another day. Alaska keeps about 3 days either side of today.
  2. Tap Get Status. Each leg of that flight number appears, with its status, tail and times.
  3. Fix the ATA (In) time on arrived legs (see below), uncheck any leg that isn't yours, and tap Send to LogTen.

Alaska shows On, not In

Alaska's flight status gives the actual departure (Out) but its arrival time is the On (touchdown) time, not block-in. Your logbook needs block-in, so for every arrived leg Flifo shows an ATA (In) box prefilled with Alaska's On time. Change it to your actual block-in time before sending, e.g. 16:12 or 1612 (24-hour, station local). If you send it unchanged, LogTen gets the touchdown time and your block time comes out a few minutes short. Past midnight is handled for you.

IBT vs ORA scheduled times

The scheduled times in eCrew are the IBT contract times. They don't always match the ORA times Alaska publishes to the public, and that difference is on purpose: the contract times are the ones that count for rig and pay.

  • Include scheduled times (STD/STA) is off by default, so Flifo never touches the scheduled times already in LogTen from Floggy-Go Schedule or Floggy.
  • Turn it on only for a flight that has no eCrew times in LogTen, for example an Alaska or Horizon flight you rode that isn't in your eCrew schedule. It sends Alaska's public (ORA) times, not IBT times.

Good to know

  • Matching: LogTen updates the flight with the same date, flight number and route, the same way Floggy-Go Schedule and Floggy build them, so Flifo fills in the flights you already imported. Anything without a match is added as a new flight.
  • Overwrites: Out, In and tail replace what LogTen has for that flight. Crew, P1/P2, duty times and everything else are left alone.
  • Swapped aircraft: if the tail changed after you sent a planned tail, run Flifo again after departure; the actual tail replaces the planned one.
  • Check the date late at night or away from base: it defaults to your device's date.
  • Flifo reads Alaska's public flight status page. If Alaska changes that page, Flifo may stop working until it's updated.

Floggy-Go Pairing

Floggy-Go Pairing reads one pairing saved from eCrew and does three things with it: works out the trip rig (what the trip should pay), sends the legs to LogTen, and writes calendar files. It is the browser version of Floggy's Calculate Rig, Parse Archive and Cal – ICS.

  1. In eCrew (Safari), open the pairing's Pairing Details.
  2. Tap Share → Options → Web Archive → Save to Files.
  3. In Floggy-Go Pairing, tap Choose pairing file and pick that file. It stays on your device.

Trip rig

The big number is Trip Pay: the best of the contract rigs (MDCR, 50% Duty, 25% TAFB), with total block (CBLK) shown for reference. The REG bucket is the daily credit RainMaker should show. How each rig was worked out, How trip pay works and Definitions at the bottom of the page explain the math in plain language.

  • A yellow Check this one box means a leg moved to another day (delay or IRROPS) or a time is still an estimate. The rig reflects the trip as flown; if you saved the original trip, run it too and compare.
  • The 4:12 daily minimum doesn't apply to training, company business, functional flights or trips you split by trade or drop, so the result can run high on those.

Send to LogTen

Each leg has a checkbox; uncheck any you don't want. Send to LogTen uses the same matching as Floggy-Go Schedule and Logbook (date + flight + route), so it updates the flights you already imported instead of adding copies. As with Schedule, send the Logbook import last: it is the record for P1/P2 and Part 121/91.

Options (tap to open) holds the switches. The line beside it lists any you've changed from the defaults.

Add to Calendar

Three buttons make the same events as Floggy's Cal – ICS, from the checked legs:

  • Flights: one event per leg, with the crew in the notes.
  • Duty: report to release for each duty day, with the legs in the notes.
  • Trip: an all-day banner across the trip.

On iPad and iPhone, tap a button, then Add All and pick the calendar. On a Mac the file downloads; open it to add it to Calendar. Times are written in UTC, so they show correctly in any time zone. Each event has the same ID Floggy gives it, so importing the same trip again, from here or from Floggy, updates the event instead of adding a second one. Preview events lists what's in each file.

If something's off

  • LogTen didn't open: tap Copy LogTen URL, paste it into Safari's address bar and tap Go.
  • Old version showing: check the version and date in the header. Refresh the page, or on iPad close the home-screen app and reopen it.
  • "Can't read this file": make sure you picked the right report in the right Floggy-Go page. Schedule needs the Personal Crew Schedule Report; Logbook needs the Pilot Logbook.
