LogTen adds new flights and updates ones it already has, matched by flight_key. Flights you have locked in LogTen are skipped without any message. LogTen package for the checked legs (what Send passes) 

    

  


  
Nothing reaches LogTen until you tap Send. Rules match Floggy 2.6 Parse Schedule and Log10 Export, with the duty code list built in. Part 121/91 is not sent: the schedule can’t tell them apart, so it comes from the logbook. Times are station local, as eCrew shows them, each with its own date: +1 marks a time on the day after the duty date. Duty on goes on the first checked leg of each duty day and duty off on the last.
